# Experimental Results Directory

This directory stores all artifacts, metrics, visualization figures, and reports generated by running `main.py`.

---

## Directory Organization

```text
results/
├── README.md
├── figures/
│   ├── time_domain_signals.png       # Comparison of Normal vs LDoS time series
│   ├── transform_comparisons.png     # 3x2 grid of FSWT, STFT, and CWT energy matrices
│   ├── feature_distributions.png     # Boxplots of the 6 features by class
│   └── all_confusion_matrices.png    # Annotated confusion matrices for all 5 experiments
├── metrics/
│   └── all_experiments_metrics.csv   # Comprehensive metrics table (Accuracy, F1, FPR, etc.)
└── reports/
    └── final_report.md               # Complete experimental markdown report
```

---

## File Summaries

1. **`metrics/all_experiments_metrics.csv`**:
   - Contains quantitative metrics for Experiments 1 through 5.
   - Includes Accuracy, Precision, Recall, F1-Score, False Positive Rate (FPR), ROC-AUC, True Positives (TP), True Negatives (TN), False Positives (FP), False Negatives (FN), Training Time, Inference Time, and Test Sample Counts.

2. **`figures/transform_comparisons.png`**:
   - Displays time-frequency representations produced by FSWT, STFT, and CWT.
   - Normal traffic appears as diffuse, low-energy background fluctuations.
   - LDoS traffic exhibits bright, periodic vertical stripes corresponding to attack pulses.

3. **`reports/final_report.md`**:
   - Comprehensive technical documentation suitable for academic submissions, project viva, or research reviews.
